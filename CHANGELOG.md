# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-04-03

### Added
- Campaign management with WYSIWYG editor (Quill 2)
- AWS SES integration — send campaigns, test emails, verify credentials
- Contact list management with CSV bulk import
- Email template CRUD with preview and editor
- Campaign analytics — delivery, opens, clicks, bounces, unsubscribes
- Settings page for AWS SES configuration and default sender
- Data tables with sorting, search, and pagination (TanStack Table)
- Dark/light theme toggle in page header
- Support and feedback dialogs in sidebar
- CI pipeline — ESLint, TypeScript, Clippy, Rustfmt
- macOS DMG release build
